# Tally — Scorekeeper

Web-first pass-and-play scorekeeper for board and card games. No accounts; all data stays in your browser.

## Supported games (MVP)

- **Yahtzee** — full scorecard with upper bonus, fixed categories, Yahtzee bonus chips
- **Phase 10** — per-round scoring with phase tracking
- **Mexican Train** — pip-count round accumulation (manual end)
- **Generic Scoreboard** — free-form +/- ledger for anything else

## Development

