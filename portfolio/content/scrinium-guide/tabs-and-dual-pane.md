# Tabs and dual pane

## Tabs

| Task | How |
| --- | --- |
| Open a new tab | ⌘T, the toolbar's new-tab button, or right-click a sidebar item → **Open in New Tab** |
| Close the tab | ⌘W (closing the last tab closes the window) |
| Next / previous tab | ⇧⌘] / ⇧⌘[ |
| Jump to a tab | Click it in the tab strip |

The tab strip appears when you have more than one tab. A new tab opens in the same folder as the current one. Each tab keeps its own history, selection and view.

## Dual pane

Press **⌥⌘D** (or click the dual-pane button) to split the window into two panes side by side. Press it again to go back to one.

- Each pane has **its own tabs**, history and view.
- The **active pane** has a colored line along its top. Click inside a pane to make it active, or press **⌘\\** to switch.
- The second pane starts in the same folder as the first.

### Copy and move between panes

| Action | How |
| --- | --- |
| **Copy** selected items to the other pane's folder | **F5** (Pane menu → *Copy to Other Pane*) |
| **Move** selected items to the other pane's folder | **F6** (Pane menu → *Move to Other Pane*) |
| **Drag** an item from one pane to the other | Drag and drop |

When you drag, Scrinium follows Finder's rules: items **move** if both folders are on the same disk, and **copy** if they're on different disks. Hold **⌥ (Option)** while dropping to always copy.

> **Note:** Dragging moves or copies only the item you grab, even if several are selected. To act on several at once, select them and use F5/F6 or copy and paste.

You can also drop items onto a **sidebar item** or onto a **folder in the path bar** to put them there.

### Remembered per folder

Whether dual pane is on is saved with the folder in the left pane. Browse to a folder you left in dual pane, and the split comes back. See [Per-folder views](#per-folder-views).
