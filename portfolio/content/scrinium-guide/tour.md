## Sidebar

The left column holds:

- **Favorites**: folders you use most. Drag to reorder.
- **Cloud**: iCloud Drive and any cloud storage such as Google Drive.
- **Devices**: your Mac's disk and anything you plug in.
- **Saved Filters**: searches you saved. This section appears once you save one.

## Toolbar

From left to right:

| Control | What it does |
| --- | --- |
| **Back / Forward** | Move through folders you've visited |
| **Up** | Go to the enclosing folder |
| **View picker** | Switch between List, Columns, Icons and Gallery |
| **View options** (sliders icon) | Sort, show hidden items, counts, tags, preview, naming rule, layout templates |
| **Dual pane** | Split the window in two |
| **New tab** | Open the current folder in a new tab |
| **Terminal** | Show or hide the built-in terminal |
| **Inspector** | Show or hide the details panel |
| **Search** | Search with operators |

## The folder area

Above the list you'll see the **path bar**: click any part of the path to jump there. With more than one tab open, a **tab strip** appears above it.

The list area is where you work with files. Right-click a file for its menu, or right-click empty space to create a new folder or file.

At the bottom, the **status bar** shows how many items are in the folder and how many you've selected.

## Optional panels

- **Inspector** (⌘I): info, tags, description and custom icon for what you've selected.
- **Preview pane** (⌥⌘P): a live look at the selected file.
- **Terminal** (⌃`): a shell at the bottom of the window.

## The menu bar

Everything in the toolbar and more is in the menus:

- **File**: new tab, new folder or file, rename, cloud downloads, close tab.
- **Edit**: copy, paste, move here, move to Trash, undo rename.
- **View**: views, counts, tags, inspector, preview, terminal.
- **Go**: back, forward, enclosing folder, home, refresh.
- **Pane**: dual pane, switch pane, copy or move to the other pane, switch tabs.

Open **Scrinium → Settings** (⌘,) for settings.
