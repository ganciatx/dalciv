# Keyboard shortcuts

These are the defaults. Change any of them in **Settings → Shortcuts**. See [Customize keyboard shortcuts](../customize/shortcuts.md).

Symbols: ⌘ Command · ⌥ Option · ⇧ Shift · ⌃ Control

## Go

| Action | Shortcut |
| --- | --- |
| Back | ⌘[ |
| Forward | ⌘] |
| Enclosing folder | ⌘↑ |
| Go to Home | ⇧⌘H |
| Refresh | ⌘R |

## Views

| Action | Shortcut |
| --- | --- |
| as List | ⌘1 |
| as Columns | ⌘2 |
| as Icons | ⌘3 |
| as Gallery | ⌘4 |
| Show hidden items | ⇧⌘. |
| Show item counts | ⌥⌘I |
| Calculate folder sizes | ⌥⌘S |
| Show tags and descriptions | ⌥⌘T |
| Show inspector | ⌘I |
| Show preview pane | ⌥⌘P |
| Show terminal | ⌃` |

## While renaming

| Key | Result |
| --- | --- |
| Return | Save the name |
| Esc | Cancel |
| Tab | Next prompt in a naming template |

## Standard Mac shortcuts

⌘, (Settings), ⌘Q (quit) and ⌘H (hide) work as in other Mac apps. FileCabinet uses a single window; use [tabs and dual pane](../browse/tabs-and-dual-pane.md) to work in several folders at once.
