# Install and first launch

## What you need

- A Mac with Apple silicon running **macOS 26 (Tahoe)** or later.

## Open the app

Open **Scrinium.app**. It starts in your home folder with your Favorites in the sidebar.

> **Note:** Version 1 is not yet signed for distribution. If macOS blocks it the first time, Control-click the app, choose **Open**, then confirm.

## Give Scrinium Full Disk Access

On first launch a sheet asks you to allow Full Disk Access. This lets Scrinium read every folder, including large coding projects and external drives, without macOS asking about each location.

1. In the sheet, click **Open Settings**. (You can also open **System Settings → Privacy & Security → Full Disk Access**.)
2. Turn on **Scrinium** in the list. If it isn't there, click **+** and add it.
3. **Quit and reopen** Scrinium.

If you click **Not Now**, Scrinium still works, but macOS shows a permission prompt the first time you open Desktop, Documents, Downloads and similar folders. Until you answer them, counts and sizes for those folders can sit on a spinner.

## What's set up for you

On first launch Scrinium creates:

- **Favorites** in the sidebar: your home folder, Desktop, Documents, Downloads and Applications.
- **Seven tags** matching Finder's: Red, Orange, Yellow, Green, Blue, Purple and Gray.
- **Three example naming templates** you can use or change: *Dated client file*, *Dewey style* and *Dated note*.

No rule is switched on until you choose one, so nothing is renamed unexpectedly.
