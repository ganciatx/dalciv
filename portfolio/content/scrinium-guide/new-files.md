The **New File** menu is in the toolbar, the **File** menu, and the right-click menu on a folder's background. Picking an item creates the file in the current folder, names it with the folder's [naming rule](../rename/naming-rules.md), and opens it in its default app. If the rule asks you to type part of the name, the file opens after you finish naming it.

Each item shows its file type icon and the app that will open it.

## What's on the menu

Built-in blanks: plain text, Markdown, CSV, rich text, HTML, JSON, Word, Excel and PowerPoint. An item appears only if an installed app can open that type, so Word, Excel and PowerPoint documents show up when Office (or Pages, Numbers or Keynote) is installed.

## Your own templates

Drop any file into the **Templates folder** and it becomes a menu item named after the file. Scrinium copies it each time you pick it. A custom file replaces the built-in item of the same type, so your own `.docx` starting point replaces the blank Word document.

Open **Settings → New File** to see the folder, choose a different one, **star** items to pin them to the top, and drag to reorder. Items no installed app can open are dimmed and hidden from the menu.

Creating a file is undoable.
