Descriptions are saved as the file's **Finder comment**, so they appear in Finder's **Get Info** window and stay with the file if you stop using Scrinium.

## Add or edit a description

**In the inspector** (⌘I): select **one** item and type in the **Description** box. It saves a moment after you stop typing, and when you click elsewhere.

**In the list**: turn on the **Description** column (**View → Show Tags and Descriptions**, ⌥⌘T) and click a cell to type. Press Return or click away to save.

To remove a description, clear the text.

> **Note:** Descriptions can be edited for one item at a time. With several items selected, the inspector edits [tags](tags.md) only.

## Search descriptions

Use the `desc:` operator, for example `desc:signed`. See [Search](../find/search.md).

## A safety copy

Some cloud services strip the extra information Finder comments are stored in. Scrinium keeps a copy of every description it writes, and **restores it onto the file** the next time it sees the file without one.

## Columns are off by default

The Tags and Description columns are off until you turn them on, and the setting is [per folder](../browse/per-folder-views.md). Turn them on for the folders where you use them.
