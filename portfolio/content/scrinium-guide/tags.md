Tags are labels you can put on any file or folder. Scrinium saves them in Finder's own format, so **Finder, Spotlight and Open/Save dialogs all see them**, and they stay if you stop using Scrinium.

## Add a tag

**In the inspector** (⌘I): select one or more items, click **Add Tag**, and choose from your tag library. A checkmark means every selected item has the tag; a dash means only some do.

**In the list**: turn on the **Tags** column (**View → Show Tags and Descriptions**, ⌥⌘T), then click a cell in it.

## Remove a tag

In the inspector, click the **×** on a tag's chip. With several items selected, this removes the tag from all of them.

## Make a new tag

In the tag picker, choose **New Tag…**:

1. Type a name.
2. Choose a color from the **color wheel**, or type a **hex code** such as `#FF6600`.
3. Click **Save**. The tag is added to the item you were editing.

### About colors

Your library can hold **any color**. Finder itself only has seven tag colors (red, orange, yellow, green, blue, purple, gray), so for tags with a custom color Finder shows **the nearest of its seven**. Scrinium shows the exact color. The new-tag form tells you which Finder color will be used.

## Manage your tag library

Open **Scrinium → Settings → Tags**:

- **Edit Color** to change a tag's color.
- Drag to reorder.
- The trash button removes a tag from the **library**. Files that already have the tag **keep it**.
- **New Tag…** to add one.

> **Note:** A tag's *name* can't be changed after you create it, because the new name would have to be written onto every file. If you need a different name, create a new tag.

## Find files by tag

Search `tag:Taxes` to list everything with that tag. See [Search](../find/search.md).

## Where tags are stored

Tag **names** are written to the files themselves. Tag **colors** and your tag list are kept in Scrinium. If you uninstall Scrinium, files keep their tags, and Finder shows them with its nearest color.
