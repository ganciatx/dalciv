# Customize keyboard shortcuts

Every action in Scrinium has a shortcut, and you can change them all. See the full list.

## Change a shortcut

1. Open **Scrinium → Settings → Shortcuts**.
2. Click the shortcut next to an action. It changes to *Press keys…*
3. Press the new combination.

| While recording | Result |
| --- | --- |
| Press a combination | It's assigned |
| **Esc** | Cancel |
| **⌫** (Delete) with no other keys | Remove the shortcut (the action stays in the menus) |

A shortcut needs at least one of **⌘, ⌥ or ⌃**, or can be a function key such as F5. Plain letters aren't accepted, so they don't interfere with typing.

## Conflicts

If two actions share the same keys, an orange note appears under both ("Also used by…"). A warning also appears for keys macOS reserves, such as ⌘Q. Scrinium still assigns them, so you decide, but only one action will respond.

## Reset

- Click the **reset arrow** next to an action to restore its default.
- **Reset All** restores every shortcut.

## Not editable

A few standard shortcuts belong to macOS or to text editing and aren't in the list: ⌘, (Settings), ⌘Q, ⌘H, and **⌘A** (select all). Copy, paste, select all and ⌘⌫ keep working normally inside text fields and the terminal.

## Menus follow your shortcuts

When you change a shortcut, the menu bar shows the new keys.
