# Saved filters

Any search can become a shortcut in the sidebar.

## Save one

1. Run a [search](search.md).
2. In the bar above the results, click **Save as Filter…**
3. Give it a name and click **Save**.

It's added under **Saved Filters** in the sidebar and remembers both the search **and** where it looked: a specific folder or This Mac.

## Use one

Click it in the sidebar. The search runs again with fresh results.

## Manage them

- **Reorder:** drag.
- **Remove:** right-click → **Remove**.

## Ideas

| Name | Search |
| --- | --- |
| Big downloads | `size:>500MB` in Downloads |
| This week | `modified:>7d` in This Mac |
| Taxes | `tag:Taxes` in This Mac |
| Unsorted screenshots | `name:Screenshot` in Desktop |
